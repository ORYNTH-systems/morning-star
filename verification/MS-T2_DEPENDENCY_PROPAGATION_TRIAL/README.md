# MS-T2 Dependency Propagation Trial

## Constitutional Status

Status: READY_FOR_EXECUTION

## Constitutional Basis

Theorem: MS-T2 — Dependency Propagation

## Objective

Verify that material semantic divergence introduced into an upstream governed object propagates measurable semantic-integrity risk to constitutionally dependent downstream governed objects unless interrupted by an independent corrective mechanism.

## Trial Artifacts

- OBJECT_REGISTRY.csv
- TRIAL_REGISTER.csv
- TRIAL_SPECIFICATION.csv
- MUTATION_REGISTER.csv

## Execution Sequence

1. Select mutation from MUTATION_REGISTER.
2. Apply mutation only to the designated source object.
3. Reconstruct every dependent governed object.
4. Measure semantic divergence.
5. Record propagated effects.
6. Determine whether propagation occurred or an admissible interruption prevented propagation.
7. Record constitutional disposition.
