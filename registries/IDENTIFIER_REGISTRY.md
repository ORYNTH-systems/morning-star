## 3. Identifier Rules

1. Every governed object has exactly one identifier.
2. Identifiers are never reused.
3. Superseded identifiers remain historically valid.
4. File names may change without changing identifiers.
5. New governed objects receive new identifiers.
6. Version changes do not change identifiers.
7. Audit findings use independent numbering.
8. Correction records use independent numbering.
9. Completion work items use independent numbering.
10. Identifier collisions block constitutional freeze.
