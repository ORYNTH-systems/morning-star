1. Purpose

This registry distinguishes major ORYNTH objects by constitutional subject, object class, responsibility, dependencies, outputs, and exclusions.

The registry is an entry-governance artifact.

It does not replace each framework's own canonical documentation.

3. Registry Rules
Every object must retain a unique identifier.
Object class must remain explicit.
Dependencies must not be interpreted as identity.
Outputs must not be interpreted as universal authority.
Exclusions must remain visible.
Candidate objects must not be represented as frozen frameworks.
Superseded identities must remain historically traceable.
Registry changes require evidence and revision records.
4. Framework Identity Test

A framework identity is sufficiently preserved when an observer can identify:

its canonical name;
its object class;
its constitutional subject;
its primary responsibility;
its required dependencies;
its outputs;
its exclusions;
its relationship to adjacent ORYNTH objects;
its authoritative source.
5. Identity Failure Conditions
name collision;
responsibility collision;
class collapse;
dependency reversal;
scope expansion without authority;
narrative substitution;
implementation substitution;
removal of explicit exclusions;
untraceable renaming;
derivative work represented as canonical origin.
6. Constitutional Result

This registry gives Morning Star a canonical orientation surface through which observers may locate ORYNTH objects without reducing the ecosystem to isolated papers or an undifferentiated architecture.
