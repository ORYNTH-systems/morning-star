# MS-T8 Trial Procedure

**Document Identifier:** MS-V1-T8-PRO-001  
**Verification Identifier:** MS-VER-T8-001  
**Version:** 0.1.0

## 1. Preparation

1. Freeze the governing Morning Star version.
2. select canonical objects.
3. register current results.
4. build complete traceability chains.
5. identify material traceability links.
6. create partial and broken variants.
7. define expected reconstructions.
8. create determinate controls.
9. register assessors.
10. freeze the scoring model.

## 2. Canonical Object Registration

For each object:

1. assign a stable object identifier;
2. record object type;
3. preserve canonical definition;
4. identify domain;
5. identify governing version;
6. identify authority source;
7. identify current status;
8. preserve canonical source.

## 3. Evidence Registration

For each evidence item:

1. assign an evidence identifier;
2. identify evidence type;
3. identify source;
4. record version;
5. record authority or provenance;
6. calculate integrity reference where applicable;
7. record uncertainty state;
8. record accessibility state.

## 4. Traceability Chain Registration

For each chain:

1. assign a chain identifier;
2. identify originating object;
3. identify result object;
4. register required links;
5. preserve link order;
6. register dependency direction;
7. register transformations;
8. register revisions;
9. register supersession state;
10. classify chain condition.

## 5. Case Construction

Create paired cases under:

- COMPLETE_TRACEABILITY;
- PARTIAL_TRACEABILITY;
- BROKEN_TRACEABILITY;
- DETERMINATE_CONTROL.

Each pair shall preserve the same underlying canonical result.

## 6. Reconstruction Task

Each observer shall:

1. identify the canonical object;
2. identify the canonical source;
3. identify the governing version;
4. identify the authority source;
5. reconstruct dependencies;
6. reconstruct transformations;
7. identify supporting evidence;
8. preserve uncertainty;
9. identify superseded states;
10. explain how the current result was produced;
11. identify missing or ambiguous links;
12. cite all used records.

## 7. Response Registration

For each response:

1. assign a response identifier;
2. identify observer;
3. identify case;
4. preserve reconstructed properties;
5. preserve cited references;
6. preserve unresolved properties;
7. preserve confidence separately from evidence;
8. record submission time.

## 8. Property Assessment

Assess each reconstructed property as:

- CORRECTLY_RECONSTRUCTED;
- PARTIALLY_RECONSTRUCTED;
- RECONSTRUCTED_WITH_UNCERTAINTY;
- INCORRECTLY_RECONSTRUCTED;
- UNSUPPORTED_RECONSTRUCTION;
- NOT_RECONSTRUCTABLE;
- INSUFFICIENT_EVIDENCE;
- DISPUTED;
- NOT_APPLICABLE.

## 9. Link Failure Assessment

For every reconstruction failure:

1. identify the affected property;
2. identify the missing or defective link;
3. classify failure type;
4. classify materiality;
5. identify whether repair is possible;
6. preserve evidence.

## 10. False Reconstruction Assessment

A false reconstruction shall be recorded when:

1. a property is asserted;
2. the chain does not support it;
3. no independent admissible evidence supports it;
4. the assertion is material;
5. the unsupported derivation is reproducible from the response.

## 11. Analysis

Calculate by condition:

- reconstruction accuracy;
- traceability completeness rate;
- provenance ambiguity rate;
- unsupported reconstruction rate;
- identity recovery rate;
- version recovery rate;
- authority recovery rate;
- dependency recovery rate;
- transformation recovery rate;
- uncertainty recovery rate;
- supersession recovery rate.

## 12. Adjudication

Where assessors disagree:

1. preserve original assessments;
2. identify the disputed property or link;
3. preserve supporting evidence;
4. conduct bounded adjudication;
5. record final result;
6. retain disagreement history.

## 13. Closure

The trial may close only when:

- all canonical objects are registered;
- all evidence references are registered;
- all chain manifests are complete;
- all case conditions are preserved;
- all reconstruction responses are collected;
- all material properties are assessed;
- false reconstructions are evaluated;
- broken links are classified;
- limitations are declared;
- analysis is reproducible;
- theorem disposition is assigned.
