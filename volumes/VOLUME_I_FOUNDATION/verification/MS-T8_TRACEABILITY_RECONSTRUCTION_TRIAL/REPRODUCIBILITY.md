# MS-T8 Reproducibility Requirements

**Document Identifier:** MS-V1-T8-REP-001  
**Version:** 0.1.0

A reproduction package shall include:

1. governing Morning Star commit;
2. theorem version;
3. trial design;
4. procedure;
5. data dictionary;
6. scoring model;
7. canonical objects;
8. canonical sources;
9. evidence references;
10. integrity references;
11. traceability-chain manifests;
12. transformation records;
13. revision records;
14. supersession records;
15. case-condition assignments;
16. reconstruction cases;
17. reconstruction responses;
18. property assessments;
19. adjudication records;
20. analysis procedure;
21. protocol deviations;
22. limitations;
23. final disposition.

A result is reproducible only when an independent evaluator can reconstruct each assessment from preserved object, chain, evidence, response, and adjudication records.
