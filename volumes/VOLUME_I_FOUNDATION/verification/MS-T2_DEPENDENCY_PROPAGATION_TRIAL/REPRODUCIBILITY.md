# MS-T2 Reproducibility Requirements

**Document Identifier:** MS-V1-T2-REP-001  
**Version:** 0.1.0

A reproduction package shall include:

1. governing Morning Star commit;
2. theorem version;
3. trial design;
4. trial procedure;
5. data dictionary;
6. scoring model;
7. canonical governed objects;
8. divergent seeded representations;
9. dependency-chain definitions;
10. dependency-edge definitions;
11. transformation rules;
12. correction mechanisms;
13. all intermediate artifacts;
14. propagation events;
15. downstream assessments;
16. analysis procedure;
17. protocol deviations;
18. limitations;
19. final disposition.

A result is reproducible only when an independent evaluator can reconstruct each propagation classification from preserved evidence.
