# MS-T3 Reproducibility Requirements

**Document Identifier:** MS-V1-T3-REP-001  
**Version:** 0.1.0

A reproduction package shall include:

1. governing Morning Star commit;
2. theorem version;
3. trial design;
4. procedure;
5. data dictionary;
6. scoring model;
7. capability vocabulary;
8. authority vocabulary;
9. scenario definitions;
10. participant capability profiles;
11. authority assignments;
12. action decisions;
13. authority assessments;
14. exception rules;
15. adjudication records;
16. analysis procedure;
17. protocol deviations;
18. limitations;
19. final disposition.

A result is reproducible only when an independent evaluator can reconstruct each action's capability status, authority status, scope determination, and final classification.
