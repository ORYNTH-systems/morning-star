# MS-T1 Reproducibility Requirements

**Document Identifier:** MS-V1-T1-REP-001  
**Version:** 0.1.0

A reproduction package shall include:

1. governing Morning Star commit;
2. trial design;
3. procedure;
4. data dictionary;
5. scoring model;
6. canonical source package;
7. governed-initiation package;
8. unrestricted-entry package;
9. trial cases;
10. de-identified observer responses where permissible;
11. semantic assessments;
12. analysis procedure;
13. protocol deviations;
14. limitations;
15. final disposition.

A result is reproducible only when an independent evaluator can reconstruct the reported measurements from preserved evidence.
