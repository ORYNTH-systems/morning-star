## Verification Basis

The controlled four-condition case set demonstrated that:

1. competence transferred accurately within the same domain and identical version;
2. materially changed version conditions produced governing-version, authority, uncertainty, and revalidation errors when obsolete knowledge was applied;
3. a related domain admitted only bounded partial transfer;
4. a distinct domain did not inherit competence or authority from the source domain;
5. transfer accuracy degraded as domain or version distance increased;
6. unsupported equivalence remained distinguishable from valid, partial, and invalid transfer.

## Scope Qualification

The theorem is supported only within the declared controlled case set.

This disposition does not establish universal empirical validity across all observers, governed domains, versions, or external environments.
