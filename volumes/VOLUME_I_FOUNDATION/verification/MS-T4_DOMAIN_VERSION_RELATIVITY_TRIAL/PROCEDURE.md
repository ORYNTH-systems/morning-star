# MS-T4 Trial Procedure

**Document Identifier:** MS-V1-T4-PRO-001  
**Verification Identifier:** MS-VER-T4-001  
**Version:** 0.1.0

## 1. Preparation

1. Freeze the governing Morning Star version.
2. select source and target domains.
3. define domain profiles.
4. define source and target versions.
5. classify version differences.
6. register material changes.
7. define required target capabilities.
8. define transfer rules where applicable.
9. create paired transfer cases.
10. freeze the scoring model.

## 2. Observer Baseline Registration

For each observer:

1. assign an observer identifier;
2. record verified source domain;
3. record verified source version;
4. record capability evidence;
5. record verification date;
6. record limitations;
7. record authority scope;
8. record expiration or revalidation conditions.

## 3. Domain Profile Registration

For each domain:

1. assign a domain identifier;
2. state canonical purpose;
3. identify governed objects;
4. identify terminology;
5. identify boundaries;
6. identify dependencies;
7. identify authority rules;
8. identify uncertainty rules;
9. identify required capabilities.

## 4. Version Profile Registration

For each version:

1. assign a version-profile identifier;
2. identify domain;
3. record version number;
4. record effective date;
5. record material properties;
6. record change class;
7. record superseded version;
8. record authority state;
9. record canonical source.

## 5. Transfer Case Construction

For each transfer case:

1. identify observer;
2. identify source domain and version;
3. identify target domain and version;
4. identify domain-distance class;
5. identify version-change class;
6. identify applicable transfer rule;
7. define expected disposition;
8. define target reconstruction task;
9. define authority-scope task;
10. define uncertainty task.

## 6. Response Collection

Each observer shall:

1. identify the target governed object;
2. reconstruct the target definition;
3. state target boundaries;
4. identify target dependencies;
5. identify governing version;
6. identify authority source;
7. preserve uncertainty;
8. state whether prior competence transfers;
9. identify required revalidation;
10. cite supporting evidence.

## 7. Transfer Assessment

Each response shall be assessed for:

- target identity;
- target definition;
- target boundary;
- dependency accuracy;
- version accuracy;
- authority accuracy;
- uncertainty preservation;
- transfer-rule accuracy;
- revalidation accuracy;
- false-equivalence claims.

Assessment values are:

- PRESERVED;
- TRANSFER_ERROR;
- NEGATIVE_TRANSFER;
- PARTIAL_TRANSFER;
- INSUFFICIENT_EVIDENCE;
- DISPUTED;
- NOT_APPLICABLE.

## 8. Transfer Disposition Assessment

Assessors shall assign:

- TRANSFER_VALID;
- TRANSFER_PARTIAL;
- REVALIDATION_REQUIRED;
- TRANSFER_INVALID;
- INSUFFICIENT_EVIDENCE;
- DISPUTED.

The disposition shall be supported by property-level evidence.

## 9. Negative Transfer Classification

Negative transfer shall be classified only when:

1. the observer applies source-domain or source-version knowledge;
2. that knowledge is invalid in the target;
3. a material target error results;
4. no stronger independent cause is established.

## 10. Analysis

Calculate by transfer class:

- reconstruction accuracy;
- transfer error rate;
- false-equivalence rate;
- negative-transfer rate;
- governing-version error rate;
- authority-scope error rate;
- uncertainty-erasure rate;
- revalidation-recognition rate;
- valid-transfer rate;
- partial-transfer rate.

## 11. Adjudication

Where assessors disagree:

1. preserve original assessments;
2. identify the disputed property;
3. preserve supporting evidence;
4. conduct bounded adjudication;
5. record final result;
6. retain disagreement history.

## 12. Closure

The trial may close only when:

- all observer baselines are complete;
- all domain profiles are complete;
- all version profiles are complete;
- material changes are classified;
- transfer cases are executed;
- all responses are preserved;
- all assessments are complete;
- transfer dispositions are assigned;
- negative transfer is evaluated;
- limitations are declared;
- analysis is reproducible;
- theorem disposition is assigned.
