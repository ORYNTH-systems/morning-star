# MS-T4 Reproducibility Requirements

**Document Identifier:** MS-V1-T4-REP-001  
**Version:** 0.1.0

A reproduction package shall include:

1. governing Morning Star commit;
2. theorem version;
3. trial design;
4. procedure;
5. data dictionary;
6. scoring model;
7. domain profiles;
8. version profiles;
9. material-change records;
10. observer baselines;
11. transfer rules;
12. transfer cases;
13. observer responses;
14. transfer assessments;
15. adjudication records;
16. analysis procedure;
17. protocol deviations;
18. limitations;
19. final disposition.

A result is reproducible only when an independent evaluator can reconstruct every transfer classification from preserved domain, version, observer, and evidence records.
