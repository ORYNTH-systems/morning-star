# MS-T5 Reproducibility Requirements

**Document Identifier:** MS-V1-T5-REP-001  
**Version:** 0.1.0

A reproduction package shall include:

1. governing Morning Star commit;
2. theorem version;
3. trial design;
4. procedure;
5. data dictionary;
6. scoring model;
7. source versions;
8. target versions;
9. material revision records;
10. compatibility rules;
11. observer baselines;
12. revalidation packages;
13. condition assignments;
14. revalidation cases;
15. observer responses;
16. assessments;
17. adjudication records;
18. analysis procedure;
19. protocol deviations;
20. limitations;
21. final disposition.

A result is reproducible only when an independent evaluator can reconstruct every post-revision assessment from preserved revision, observer, and evidence records.
