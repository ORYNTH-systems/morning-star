# MS-T6 Reproducibility Requirements

**Document Identifier:** MS-V1-T6-REP-001  
**Version:** 0.1.0

A reproduction package shall include:

1. governing Morning Star commit;
2. theorem version;
3. trial design;
4. procedure;
5. data dictionary;
6. scoring model;
7. source evidence objects;
8. source uncertainty classifications;
9. canonical preserving responses;
10. prohibited unsupported-certainty responses;
11. condition assignments;
12. trial cases;
13. observer responses;
14. uncertainty transformations;
15. assessments;
16. adjudication records;
17. analysis procedure;
18. protocol deviations;
19. limitations;
20. final disposition.

A result is reproducible only when an independent evaluator can reconstruct each uncertainty transformation from preserved source evidence and response records.
