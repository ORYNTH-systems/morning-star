## Purpose

This workspace receives candidate evidence before governed registration.

Files placed here are not automatically admissible evidence.

## Submission Directories

- input/ — initial governed state.
- constraints/ — constraint applicability and satisfaction material.
- 	race/ — ordered transition and execution records.
- output/ — resulting governed state.
- uncertainty/ — missing, approximate, contradictory, or unresolved material.

## Submission Rules

Each submitted item must later be assigned:

- one evidence identifier;
- one evidence class;
- one source path;
- one acquisition description;
- one provenance status;
- one uncertainty status;
- one or more governing requirement references.

## Constitutional Boundary

Placing a file in this workspace does not:

- register the file as evidence;
- establish provenance;
- establish admissibility;
- satisfy an evidence requirement;
- authorize theorem evaluation;
- establish a verification result.
