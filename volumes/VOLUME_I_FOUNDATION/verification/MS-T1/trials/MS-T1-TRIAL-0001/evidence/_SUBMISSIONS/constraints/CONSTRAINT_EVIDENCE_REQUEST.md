# Constraint Evidence Request

## Trial

- Trial ID: MS-T1-TRIAL-0001
- Theorem ID: MS-T1
- Evidence class: CONSTRAINT
- Collection state: REQUEST_PREPARED

## Required Material

Provide evidence sufficient to determine:

- which constitutional constraints applied;
- where each constraint originated;
- whether each constraint was active;
- whether any exception or waiver existed;
- whether scope, role, dependency, authority, or uncertainty boundaries changed.

## Required Qualification

For every claimed constraint, preserve:

- constraint identity;
- authority source;
- version or effective state;
- applicability basis;
- satisfaction evidence;
- unresolved ambiguity.

An unproven constraint must remain unproven.
