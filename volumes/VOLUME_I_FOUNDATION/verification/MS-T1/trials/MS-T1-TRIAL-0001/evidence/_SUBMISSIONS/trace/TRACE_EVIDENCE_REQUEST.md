# Trace Evidence Request

## Trial

- Trial ID: MS-T1-TRIAL-0001
- Theorem ID: MS-T1
- Evidence class: TRACE
- Collection state: REQUEST_PREPARED

## Required Material

Provide an ordered record of material events from initial entry through the resulting state.

Each event should identify, where available:

- event sequence;
- event time;
- prior state;
- new state;
- action or transformation;
- actor or runtime;
- authority reference;
- evidence reference;
- uncertainty or interruption.

## Constitutional Requirement

The trace must preserve dependency order and may not silently remove failed, blocked, reversed, skipped, or unknown events.
