# MS-T7 Reproducibility Requirements

**Document Identifier:** MS-V1-T7-REP-001  
**Version:** 0.1.0

A reproduction package shall include:

1. governing Morning Star commit;
2. theorem version;
3. trial design;
4. procedure;
5. data dictionary;
6. scoring model;
7. canonical source claims;
8. scope profiles;
9. canonical bounded interpretations;
10. prohibited expanded interpretations;
11. valid derived-expansion evidence;
12. condition assignments;
13. interpretation cases;
14. observer responses;
15. scope assessments;
16. adjudication records;
17. analysis procedure;
18. protocol deviations;
19. limitations;
20. final disposition.

A result is reproducible only when an independent evaluator can reconstruct every scope assessment from preserved claim, scope, evidence, and response records.
