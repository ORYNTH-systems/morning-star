# Morning Star Interpretation Governance Rules

**Document ID:** MS-V4-GOV-001  
**Version:** 0.1.0  
**Status:** INTERPRETATION FOUNDATION  

## Evaluation Order

Every interpretation must be evaluated in this order:

1. source identity
2. source status
3. interpretation identity
4. interpretation class
5. interpreter identity
6. role authority
7. interpretive authority
8. scope
9. dependencies
10. source basis
11. provenance
12. uncertainty
13. equivalence claim
14. prohibited conflation review
15. version currency
16. constitutional invariant review
17. admission result

## Canonical Admission Rule

No interpretation may receive CANONICAL classification unless canonical authority, exact semantic preservation, dependency preservation, scope preservation, provenance, and equivalence have been verified.

## Derived Authority Rule

A derivative interpretation inherits source traceability.

It does not inherit source authority automatically.

## Scope Rule

Interpretive conclusions must remain within the scope supported by source, method, evidence, and authority.

## Uncertainty Rule

Material uncertainty must remain visible in both the interpretation object and every downstream use.

## Conflict Rule

Conflicting interpretations must remain distinct until a governed resolution occurs.

## Reconstruction Rule

Interpretive reconstruction must preserve the original drifted interpretation and produce a new traceable version.

## Role Rule

Technical access must not be treated as interpretive authority.

## Determinism Rule

Equivalent constitutional inputs must produce equivalent interpretation admission results.
